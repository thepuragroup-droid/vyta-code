THE REVIEW STANDARD

What each status means.

Review status describes the evidence available, not a guarantee that a code will apply to your order.

Not reviewed
No publishable review is available. This does not mean a code is invalid.
Settings reviewed
The recorded configuration has been inspected; checkout success has not been demonstrated.
Manually tested
A reviewer observed the stated result under specific conditions at the recorded time.
Needs recheck
The review is stale, incomplete or affected by a change in terms.
Expired
A documented expiry has passed.
