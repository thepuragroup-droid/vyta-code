Understand Code verified in cart, Settings reviewed, Not reviewed, Needs recheck and Expired labels used in VYTA code records.

✓ Code verified in cart
A supplied screenshot shows the code applied in a cart or checkout summary. The accompanying date and time identify that screenshot. This is a historical observation, not a claim that the code is active for all orders today.
Settings reviewed
A configuration screen has been inspected. It can describe how a code was configured, but does not demonstrate that an eligible cart accepted it.
Not reviewed
No supported review is available for the entered code. It does not mean the code is invalid.
Needs recheck
The evidence is incomplete, conflicting, or marked for another review. A fresh result is needed before a success label is used.
Not applied in screenshot
The supplied screen does not show a successful application under those conditions. This does not prove that every other cart would fail.
Expired
A documented expiry has passed. Age alone is not used to invent an expiry date.

Does “verified” mean a completed purchase?

No. Our screenshot-based label records what was visible in the supplied cart or checkout summary. A completed order, payment or live validation request is not implied.
