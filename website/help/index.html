Make sense of a code result.

A code may depend on region, eligible items, expiry, minimum spend and combination rules.

Why is my code not found?

This site includes manually reviewed screenshot records. An absent result does not establish whether a code exists or works.

Can I upload a screenshot here?

No. Authorized team members use the private review folder. Customer, payment and credential information must be removed before uploading.

Does a manual review guarantee eligibility?

No. A review applies to the stated conditions and time. Terms and eligibility can change.
